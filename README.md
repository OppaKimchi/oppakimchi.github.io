# Vitou Seng's portfolio

A single-page React and TypeScript site, deployed to GitHub Pages by GitHub Actions.

## Run it locally

```bash
npm install
npm run dev
```

## Edit the content

All of the text lives in `src/content.ts`. To add a project, add an entry to the `projects` list.

Do not add an email address, phone number, clearance numbers or other identifiers. The site is public.
